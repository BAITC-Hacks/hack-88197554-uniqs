# Career Quest — старт проекта

Статус на 23 сентября 2026: выбран кейс Career Quest; финальный сюжет, стек и оформление ещё обсуждаются. Этот документ фиксирует направление работы, а не готовность приложения.

## Задача

Помочь сотруднику понять, как конкретные активности приближают его к карьерной цели. AI предлагает 1–3 следующих шага на основе профиля, требований следующего грейда и истории участия и объясняет выбор. HR получает срез по разрывам в компетенциях и участию в развитии.

Основной пользователь — сотрудник; второй пользователь — HR.

## Визуальное направление в обсуждении

Пиксельный город с видом сбоку и постепенно развивающимися зданиями. Ориентир по восприятию пространства — Terraria; сюжет, персонажи и визуальные материалы будут собственными.

Возможная механика: направления навыков представлены зданиями или участками, а завершённые активности меняют их внешний вид. Ответы на вопросы уточняют карьерную цель и рекомендации. Изменение навыка отражает правила датасета, а не произвольную игровую награду.

Открытые вопросы:

- Какой сюжет связывает сотрудника с городом?
- Что обозначает здание: направление навыков, конкретный навык или карьерную цель?
- Каким будет заметное изменение после первого завершённого шага?
- Как связать личный город с полезным обзором для HR?

Публичных рейтингов сотрудников не будет. Визуальная механика не должна подменять объяснение карьерного прогресса.

## Обязательные фичи независимо от сюжета

| Фича | Видимый результат |
| --- | --- |
| Профиль и траектория | Роль, грейд, навыки, история и требования целевого уровня |
| AI-навигатор | 1–3 подходящие активности с объяснением минимум по трём факторам |
| Завершение активности | Обновлённые навыки и прогресс по правилам gain и max_level |
| Город | Видимое изменение сцены, связанное с рассчитанным прогрессом |
| HR-обзор | Частые разрывы навыков, сотрудники без следующего шага, участие по активностям |
| Загрузка данных | Дополнительные профили и история в формате датасета для проверки жюри |

Границы папок, общие контракты и владельцы фич определяются после выбора стека. До этого разделение выше — продуктовая декомпозиция.

## Минимальный сквозной сценарий

1. Открыть сотрудника и его карьерную цель.
2. Показать текущие навыки и разрывы до целевого грейда.
3. Получить рекомендацию с объяснением, учитывающим требования и историю участия.
4. Отметить рекомендованную активность выполненной.
5. Показать изменение навыков и соответствующее изменение города.
6. Открыть HR-обзор и загрузить дополнительный проверочный профиль с историей.

## Предварительный план на пять часов

Каждый час — содержательный коммит и push в рабочую ветку. План ниже является ориентиром, а не отчётом о выполненных работах. В main изменения принимает интегратор.

| Этап | Результат к очередному push |
| --- | --- |
| 1 | Выбранный сценарий, согласованные контракты, каркас и профиль на фикстуре |
| 2 | Рекомендации на фикстуре с объяснением и первая версия сцены |
| 3 | Реальная AI-рекомендация, завершение активности и обновление прогресса |
| 4 | HR-обзор и загрузка проверочных данных |
| 5 | Проверка сквозного демо, исправления и инструкция запуска |

Внешний AI-сервис подключается после рабочего сценария на фикстуре. Геймификация остаётся надстройкой над корректной рекомендацией и расчётом навыков.
