# Playbook — чего придерживаться

## Вечером
- У обоих работает Claude Code и не спрашивает разрешения на каждый шаг (allow-list или bypass-режим).
- Договориться о зонах: один — мозг агента и backend, второй — UI, демо, деплой.
- Решить, на чьей машине живёт интегратор (docs/INTEGRATOR.md). Проверить, что `claude --model claude-fable-5-1` запускается.
- Ключи API (какие дадут или какие есть) — в `.env` у обоих.

## Когда дадут репо и трек — первые 30 минут, вместе, без кода
1. Скопировать в репо `CLAUDE.md`, `.claude/`, `scripts/`, `docs/`.
2. Идея → одно предложение + 3 «вау»-момента → CLAUDE.md и docs/DEMO.md.
3. Стек — самый скучный из знакомых → CLAUDE.md. Вписать проверки в `scripts/check.sh`.
4. Граница между зонами: 1–3 эндпоинта или типа → docs/DECISIONS.md.
5. TODO: 5–8 задач, каждая = видимый кусок демо, у каждой владелец.

## Первый час
- Пустое приложение запускается, check.sh зелёный, hello-world задеплоен по URL. Только потом фичи.

## Цикл на задачу
```
/task → (план, если > 20 мин) → код → /check → commit → /sync
```
- Агент крутится > 20 минут без результата — стоп, сузить задачу.
- Хочется «ещё фичу» — сначала проверить, есть ли она в DEMO.md.

## Каждые 2 часа
- Интегратор: `/integrate` → деплой → `/demo prod`. Сломано — чиним, нового не начинаем.
- `/handoff`, если кто-то уходит.

## Что показать жюри
- Один агент, 3–5 инструментов. Мультиагент — только если это сам продукт.
- Шаги агента и вызовы инструментов видны, стримом.
- Ошибки инструментов обрабатываются и видны, а не роняют приложение.

## Последние 3 часа
- Freeze фич. Только демо-путь, README, деплой, стабильность.
- Записать видео демо на случай, если прод или API лягут на сцене.
- Репетиция питча ×2 с таймером.

## Красные флаги
- Оба правят один файл → пересмотреть зоны.
- Интегратор второй раз отказывает одной ветке → сузить задачу, не спорить с ним.
- Час без коммита → коммит WIP.
- «Давай auth / нормальную архитектуру» → нет.
- Агент предлагает новый фреймворк → нет.

## Мерж: один интегратор
- Только агент-интегратор вливает в main: Claude `claude-fable-5-1` в основном checkout. Правила в docs/INTEGRATOR.md.
- Запуск: `orca terminal create --worktree path:<репо> --title "Integrator" --command "claude --model claude-fable-5-1 --effort high"`, в сессии `/integrate` или `/loop 20m /integrate`.
- Воркеры пушат свои ветки и делают `/sync`, чтобы подтянуть main. Интегратор отказал — чинить по его строке.

## Worktree: грабли
- `.env` и зависимости не копируются. `scripts/setup-worktree.sh` поставить setup-хуком репо в Orca или запускать руками.
- Одна ветка — один worktree. Main открыт только у интегратора.
- У каждой фичи свой порт dev-сервера (3001, 3002, …), писать в промпт задачи.
- Слитые worktree удалять: `orca worktree rm`, иначе путаница в `orca worktree ps`.

## Orca (установлена, 1.4.207)
Уровень 1, основной: человек раздаёт задачи, Orca держит worktree, терминалы, дифф и аккаунты.
- `orca open`, затем `orca status` должен показать `runtimeReachable: true`.
- `orca repo add --path <репо>`. В настройках репо задать setup-хук: установка зависимостей и копия `.env`.
- Скелет: `orca worktree create --name skeleton --agent claude --prompt "$(cat prompts/skeleton.md)" --activate --json`
- Fan-out по фичам, по одной команде на фичу, PORT в промпте:
  `orca worktree create --name f1 --agent codex --prompt "$(cat prompts/f1.md)" --json`
- Готово: скриншот и дифф в Orca, пометка на строке диффа уходит агенту, Commit & push, дальше `/integrate` у интегратора, потом `orca worktree rm`.
- Для Codex-воркеров есть встроенный браузер через CLI (`orca snapshot`, `orca screenshot`), так что «покажи скриншот» выполнимо и без Claude.

Уровень 2, только если вечером завёлся за 15 минут: Claude как координатор, Codex как воркеры.
- `orca orchestration run-create --objective "<цель>" --json`
- На фичу: `orca orchestration worker-start --spec "$(cat prompts/f1.md)" --worktree new-child --agent codex --model <id> --effort high --json`
- Ждать: `orca orchestration check --wait --types "worker_done,escalation,question" --timeout-ms 900000 --json`
- Effort задаётся на воркера: логика high или xhigh, UI medium.
