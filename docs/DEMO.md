# Демо-сценарий (3 минуты)

Задача существует, только если она есть в этой таблице.

**Проблема:** сотрудник получает поток разрозненных HR-активностей без связи с его ростом и проходит их формально, а бюджет на развитие тратится полностью.
**Решение:** AI-наставник, который по профилю, истории участия и требованиям следующего грейда предлагает 1–3 шага, объясняет каждый минимум по трём факторам и показывает, как шаг сдвигает к повышению.
**Три «вау»-момента:**
1) Наставник думает вслух: в UI видны шаги агента и вызовы инструментов, а итоговый шаг — не «самый низкий навык».
2) Город карьеры: персонаж идёт к юрте наставника, над площадкой квеста загорается «!», после «Выполнено» над персонажем всплывает «+1», прогресс этажа в башне отдела сдвигается, наставник перестраивает план.
3) Загружаем новый профиль в формате жюри → рекомендация с объяснением меньше чем за 10 секунд.

**Герой демо: E0028** (Backend Engineer, Middle → Senior, цель не задана). Этот профиль — пример из ТЗ, и на нём ломаются оба простых правила:
- Самый низкий навык — Cloud (1). Правило «бери минимальный навык» даст EV_009 Cloud Certification Prep, а в истории по нему два `dropped` (март и апрель 2026).
- Критичный для Senior System Design в профиле равен 2, но EV_006 Designing High-Load Systems завершён 2026-09-08, уже после ревью 2026-06-24. Значит, реально 3. EV_006 и EV_007 уже пройдены и повтору не подлежат, поэтому правило «качай критичный навык» тоже промахивается.
- В истории видна закономерность: воркшопы и менторство, выбранные самостоятельно, завершены, а сертификации и курсы брошены. Наставник должен это учесть.
- Запасные профили-ловушки для проверки движка: E0072, E0052, E0026.
