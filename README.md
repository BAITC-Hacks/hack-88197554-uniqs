<h3 align="center">Карьера как город: этажи башен — грейды, AI-наставник в юрте объясняет каждый следующий шаг.</h3>

Сотрудник ходит по 3D-городу своей компании. У каждого отдела своя башня, этаж в ней — текущий грейд. AI-наставник по профилю, истории участия и требованиям следующего грейда подбирает 1–3 активности и объясняет выбор минимум по трём факторам. Пройденная активность поднимает навыки и приближает к следующему этажу. HR видит, какие компетенции проседают и у кого нет следующего шага, без публичных рейтингов.

## Getting started

Clone the repository and open the project directory:

```bash
git clone https://github.com/BAITC-Hacks/hack-88197554-uniqs.git
cd hack-88197554-uniqs
```

Установить зависимости и запустить (Node 20+):

```bash
npm install
npm run dev
```

Откройте http://localhost:3000. Датасет стартового кита в git не хранится: положите `employees.json`, `events.json`, `skills.json`, `activity_history.csv` в `data/` или задайте `DATASET_ZIP=/путь/к/career_quest_dataset.zip` — `npm run dev` распакует его сам.
