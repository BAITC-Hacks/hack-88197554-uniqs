# Career Quest — офис компании

Самостоятельный прототип из ветки `codex/office`: одно здание компании, восемь отделов,
200 индивидуальных персонажей, совместное присутствие и личная карьерная панель.

**Статус, ограничения и задачи интеграции:** [отдельное техническое задание](../../docs/OFFICE_SPEC.ru.md).
Основное приложение Next.js остаётся в корне репозитория. Этот прототип запускается отдельным процессом.

## Запуск готовой версии

Требуется Node.js 20+. Установка npm-зависимостей для готовой сборки не нужна.

1. Получите стартовый кит хакатона. Положите `employees.json`, `events.json`, `skills.json`
   и `activity_history.csv` непосредственно в корневую папку `data/` репозитория.
   Датасет не включён в Git согласно правилам проекта.
2. В корне репозитория выполните:

```sh
node prototypes/office/server.mjs
```

3. Откройте **http://127.0.0.1:4180**. Сервер должен оставаться запущенным.

Можно использовать уже распакованный датасет по другому пути:

```powershell
$env:WORLD_DATA_DIR = 'C:\path\to\career_quest_dataset'
node prototypes/office/server.mjs
```

```sh
WORLD_DATA_DIR=/path/to/career_quest_dataset node prototypes/office/server.mjs
```

Порядок поиска: `WORLD_DATA_DIR` → локальная `prototypes/office/data/` → корневая `data/`.
Во всех случаях файлы JSON/CSV должны лежать непосредственно в выбранной папке.

## Совместное присутствие

Откройте адрес в двух браузерах и выберите разных сотрудников. Позиции передаются через SSE,
команды движения — через HTTP. Сервер проверяет препятствия и занятость персонажа.
Каждый браузер хранит свою сессию в sessionStorage; один сотрудник доступен одному участнику.

Для второго компьютера в той же локальной сети используйте LAN-адрес из консоли сервера
или окна «Пригласить коллегу». Выберите адрес сетевого адаптера, доступного второму компьютеру.
Соединение зависит от сети и разрешённого доступа к порту 4180. Интернет-деплой не выполнен.
Сервер по умолчанию слушает `0.0.0.0`. Для доступа только с текущего компьютера задайте
`WORLD_HOST=127.0.0.1`; порт меняется через `WORLD_PORT`.

## Управление

- «Войти в компанию» — выбрать свободный профиль из датасета.
- WASD / стрелки — ходьба; клик по полу — маршрут к точке.
- Перетаскивание левой кнопкой — вращение камеры; правой — сдвиг; колесо — масштаб.
- «Здание / Офис» — внешний вид или разрез здания.
- Отдел или пространство слева — приблизить помещение и направить туда выбранного сотрудника.
- «На меня» — приблизить своего персонажа; «Весь офис» — общий вид.
- Карточка активности — объяснение выбора и ожидаемый прирост навыков.

Остальные персонажи перемещаются автоматически; они не учитываются в счётчике «онлайн».
Реальных участников отмечает зелёное кольцо, собственного персонажа — отдельная подпись.

## Сборка и проверки

Все команды ниже выполняются из корня репозитория:

```sh
npm --prefix prototypes/office ci
npm --prefix prototypes/office run build
node --test prototypes/office/test/world.test.mjs
```

Сборка использует модели из `public/models/furniture/`, создаёт `world.html` со встроенными
моделями, текстурой, JS и CSS. Внешние CDN не нужны. Для тестов также нужен локальный датасет.
Зависимости прототипа изолированы от Next.js: Three.js 0.180.0 и esbuild 0.25.9.

## Данные и ограничения

Срез данных — **2026-10-01**. Завершённые активности после `last_review_date` доначисляют
навыки по `gain` и `max_level`. Подбор использует роль, грейд, prerequisites, цель, пробелы,
формат и историю; обязательное обучение исключается. Сейчас это детерминированный подбор,
LLM не подключена. Прогулка в академию не отмечает обучение пройденным.

Выбор профиля — демонстрационный вход, без проверки личности и разграничения сотрудник/HR.
Сессии и координаты находятся в памяти. Через 45 секунд без heartbeat персонаж освобождается;
перезапуск сбрасывает сессии и позиции. Внешность привязана к ID исходных 200 сотрудников.
Личный профиль запрашивается через `/api/me`, однако любой посетитель демо может выбрать
свободный синтетический профиль. Использовать только предоставленные синтетические данные.

## Структура

```text
src/          UI, клиент сети, 3D-сцена
shared/       план офиса, навигация и параметры персонажей
lib/          чтение датасета и демонстрационный подбор активностей
server.mjs    HTTP, сессии, координаты и SSE
build.mjs     сборка автономного фронтенда
world.html    готовый фронтенд; открывать через сервер
test/         существующие проверки данных, маршрутов и нескольких клиентов
licenses/     лицензии моделей и Three.js
```

Мебель KayKit Furniture Bits — CC0, Three.js — MIT; тексты лицензий находятся в `licenses/`.
Здание и персонажи создаются процедурно. Галерея ассетов и посторонние файлы рабочего
компьютера в этот модуль не входят.
