# Передача прототипа офиса

Дата: 2026-09-23. Ветка: `codex/office`, основана на `main` (`aa2fe28458c1150769bb36af7102d413d38fd142`).

## Состав

- Самостоятельный прототип в `prototypes/office/`: исходники, Node-сервер, готовый `world.html`,
  lock-файл изолированных зависимостей, существующие проверки и лицензии.
- Отдельное [ТЗ на текущее состояние и дальнейшие работы](../../docs/OFFICE_SPEC.ru.md).
- Модели для пересборки берутся из уже существующей `public/models/furniture/`.
- Датасет не включён в коммит. Подключается локально из `data/` либо через `WORLD_DATA_DIR`.
- Общие файлы, зависимости и маршруты основного Next.js-приложения не изменялись.

## Проверено

- Сборка упакованного прототипа на Node.js 24.19.0: успешно, встроено 15 моделей.
- Все пять существующих проверок упакованного прототипа: успешно.
- Исходная версия просмотрена в браузере; два клиента входили под разными сотрудниками,
  получали общий онлайн и перемещения. Перенос не меняет UI и схему сетевого взаимодействия.

## Общая проверка репозитория

`./scripts/check.sh` запущен, но не прошёл: `next` отсутствует после неудачной установки
зависимостей основного проекта. До проверки попытки `npm ci` с npm 9.5.0 и npm 11.6.0
завершились одинаковой ошибкой согласованности исходного lock-файла:

```text
Missing: @emnapi/runtime@1.11.3 from lock file
Missing: @emnapi/core@1.11.3 from lock file
```

Корневые `package.json` и `package-lock.json` не исправлялись в этой ветке. Поэтому нельзя
считать, что typecheck/lint всего приложения пройдены. Это не мешает запуску готового
офиса: его сервер использует встроенные модули Node, а фронтенд уже собран.

Интеграция в Next.js, подключение AI, HR, импорта и записи прогресса остаются задачами из ТЗ.
Публичный деплой и слияние в `main` не выполнялись.
