description: Интегратор - принять готовые ветки фич в main, проверить, запушить
argument-hint: [ветка — принять только её]
---
Ты интегратор. Сначала прочитай docs/INTEGRATOR.md и следуй ему. Если передан аргумент, принимай только эту ветку: $ARGUMENTS

1. Убедись, что ты в основном checkout на `main` и нет незакоммиченных изменений. Иначе остановись и скажи.
2. `git fetch --all --prune`, `git pull --ff-only origin main`.
3. Кандидаты: `git branch --no-merged main` и `git branch -r --no-merged origin/main`. Пропусти ветки без новых коммитов с прошлого прохода.
4. На каждую ветку, в порядке из docs/INTEGRATOR.md:
   - `git diff main...<ветка> --stat`, затем полный дифф. Проверь по списку «Ветка не принимается».
   - Не принимается → запиши причину, дальше.
   - `git merge --no-ff <ветка>`. Конфликт: добавочный — реши, смысловой — `git merge --abort` и в отказ.
   - `FAST=1 ./scripts/check.sh`. Красный: чини до 5 минут, иначе `git revert -m 1 HEAD` и в отказ.
5. После пачки: полный `./scripts/check.sh`, первый шаг docs/DEMO.md во встроенном браузере (скриншот). Затем `git push origin main`.
6. Обнови docs/TODO.md и статусы в docs/DEMO.md, закоммить `chore(integrate): ...`, запушь.
7. Ответ — таблица: ветка → влита / отказ → причина или что исправить. Последняя строка: «Воркерам: `/sync`, чтобы подтянуть main».
